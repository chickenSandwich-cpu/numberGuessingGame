# 😢 Number Guessing Game - Powered By chickenSandwich!!!!🔥🐤🥪🔥

Welcome to the **Number Guessing Game**, where you try to guess the number that the computer randomly-secretly selected from 1-100 👀👀

## 🚀 How to Play
1. The game will pick a **random number**😱😱
2. You try to guess it in **as few attempts as possible**😏😏
3. The game will tell you if your guess is **too high or too low**⬆️⬇️
4. Keep guessing until you **win**🏆🏆

## 🔧 Technologies Used

- **Random Number Generator**(kinda)
